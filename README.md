# KPatience (kpat)

KPatience is a collection of solitaire card games for KDE. It includes popular variants like Klondike, Spider, FreeCell, and many more. The application provides a clean, configurable interface with game statistics, hints, and undo/redo functionality.

This is an **Aurelis Linux** package built as an AppImage. It can also run as a regular AppImage on any Linux distribution without installation.
